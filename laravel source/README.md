# TravelEase Laravel API

This directory retains the original Laravel application and `/hello` route. The assignment implementation adds versioned REST APIs, MySQL migrations, Sanctum session authentication, policies, services, and tests.

The React SPA is in `../travelease-frontend/`. Start and test instructions: [workspace README](../README.md), [setup](../docs/setup-guide.md), and [testing report](../docs/testing.md).

Use PHP 8.4 with the locked Composer dependencies. In this environment use `/usr/bin/php`, not the Lerd wrapper. No real travel inventory or financial provider is connected.
